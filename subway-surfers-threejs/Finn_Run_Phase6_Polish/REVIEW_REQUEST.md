# Finn visual review packet

To complete Phase 6's visual selection, provide:

1. Current runtime `public/assets/glb/finn.glb` (confirm the actual configured path first). The referenced `finn_v2_rigged.blend` is optional for this material pass.
2. JSON output from `auditFinn(root, animations)` after the current loader's material adjustments and before polish.
3. Matched original/soft/shaped screenshots: front pre-game, running rear view and the darkest current section. Same pose, camera, lights and exposure for each comparison. Include a normal gameplay-size frame so readability can be judged.
4. The Phase 5 baseline and Phase 6 comparison results, including remaining untested checks.

Keep the original GLB unchanged. This review packet lets us evaluate Finn's actual texture and silhouette and choose the material values. Until those images are available, the supplied settings remain candidates, not a finished visual treatment.

After this material pass is selected, only commission texture work if the captures show a concrete remaining defect (for example, unreadable jersey artwork or a damaged UV seam). Any such work needs the original UV texture and a new explicit scope; do not replace Finn with an image-to-3D result.
