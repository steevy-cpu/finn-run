# Finn Run — Phase 7A: Arturo character design

Character Study 01 · 2026-09-13 · design candidate for review

## Delivered

`Arturo_Character_Study_01.png` is a 2048 × 1360 character sheet generated from the supplied Arturo portrait, with Finn's mascot artwork as a style reference. It contains a front view, back view, running pose and facial close-up. This is one proposed design, not three alternatives.

The sheet retains the portrait's short curls, expressive smile, subtle facial hair, hoop earrings, black jersey and ivory neckline. Joggers, trainers, cyan piping and the unseen back of the outfit are proposed designs. They are not claims about clothes shown in the portrait.

There is no GLB, armature, animation or game integration in this package. A PNG cannot establish topology, weights, collision behavior, polycount or runtime performance. The views are artistic references, not calibrated orthographic projections; reconcile small silhouette differences during modeling.

## Visual review

The main identity cues and outfit remain visually consistent across the sheet. All full-body views include the shoes. The pose and expression read as a playful human rival. The rendered curls and jersey perforations are more detailed than the intended game geometry: preserve their overall appearance with simplified meshes and texture detail.

Please choose whether the face, outfit and degree of stylization are right before commissioning the 3D character. Compare him with the actual polished Finn when possible. Finn's current runtime GLB and Phase 6 screenshots were not available for a side-by-side render here.
